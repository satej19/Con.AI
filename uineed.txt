1. GLOBAL DESIGN SYSTEM & THEME
--------------------------------------------------------------------------------
- Theme: Modern Dark / Light Mode with sleek construction/industrial aesthetics
- Colors:
  * Primary: Deep Slate / Navy (#0F172A, #1E293B)
  * Accent / Brand: High-visibility Amber / Industrial Orange (#F59E0B, #EA580C)
  * Status Colors:
    - Success (Received, Active, Completed): Emerald (#10B981)
    - Warning (Low Stock, Planning, On Hold, Partially Received): Amber (#F59E0B)
    - Danger (Cancelled, Waste, Defective, Overuse): Rose (#F43F5E)
    - Info / Neutral: Sky (#0EA5E9), Slate (#64748B)
- Typography: Inter, Outfit, or Plus Jakarta Sans
- Layout: Responsive Sidebar Navigation with collapsible states, Header with Project Switcher & User Profile dropdown, Breadcrumbs, Toast Notifications (Sonner/Hot-Toast).

--------------------------------------------------------------------------------
2. USER ROLES & PERMISSION MATRIX (RBAC)
--------------------------------------------------------------------------------
Roles:
1. admin         -> Full access to all modules, user role/status management, projects, POs, inventory, waste, plans, analytics.
2. manager       -> Access to projects, materials, suppliers, PO creation/approval, inventory review, plans, analytics, reports.
3. engineer      -> Access to project overview, PO creation (drafts), waste reporting, consumption planning & updates, inventory ledger.
4. store_keeper  -> Access to PO receiving (GRN), inventory issue & return, waste reporting, stock ledger.
5. viewer        -> Read-only access to dashboard, inventory, materials, suppliers, projects.

4. REUSABLE UI COMPONENTS TO BUILD
================================================================================
1. `AppLayout`: Collapsible Sidebar, Header, Breadcrumbs, User Profile Popover, Theme Toggle
2. `ProjectSelect`: Dropdown to select and switch active project context
3. `StatCard`: KPI Metric card with title, icon, value, change indicator, and trend pill
4. `DataTable`: Generic reusable table with pagination, sorting, search filter, and skeleton loading
5. `StatusBadge`: Dynamic color-mapped badge for PO statuses, Project statuses, and User roles
6. `ConfirmModal`: Confirmation dialog for irreversible actions (deactivation, cancellations, issue/return)
7. `QuantityInput`: Numeric input with increment/decrement buttons and unit label attachment
8. `DateRangePicker`: Calendar date range selector for logs and transactions
9. `EmptyState`: Clean illustration/icon with call-to-action button when data is empty
10. `ToastProvider`: Global toast notifications for all API success and error responses
